## [1.0.0] - 2026-11-15

### Added · Thêm mới

- Gradio UI for text-to-image generation with `Qwen/Qwen-Image-2512`. /
  Giao diện Gradio tạo ảnh từ văn bản với `Qwen/Qwen-Image-2512`.
- ARM64 CUDA 13 Docker image for NVIDIA DGX Spark. /
  Ảnh Docker ARM64 CUDA 13 cho NVIDIA DGX Spark.
- Bilingual Vietnamese–English code, UI labels, and documentation. /
  Mã nguồn, nhãn giao diện và tài liệu song ngữ Việt–Anh.
- GitHub Actions: CI (lint), image publish to GHCR, and release automation. /
  GitHub Actions: CI (lint), đăng ảnh lên GHCR và tự động phát hành.
- GitLab CI mirror with lint and tag release jobs. /
  GitLab CI mirror với job lint và phát hành theo tag.
- Normalized authorship and co-author trailers across the repository history. /
  Chuẩn hoá tác giả và trailer đồng tác giả trên toàn bộ lịch sử kho mã.
